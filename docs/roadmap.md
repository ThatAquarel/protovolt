# Roadmap

Planned work is tracked in [GitHub Issues](https://github.com/flakeblade/protov/issues).
Critical and security issues are addressed first, followed by feature
additions, then non-critical bug fixes and quality-of-life improvements.

> [!TIP]
> Feeling inspired to add or fix something? See the
> [contributing guide](../CONTRIBUTING.md).

## Embassy

The current set of [Embassy](https://embassy.dev) versions will remain the supported development
environment. Version bumps are unlikely unless they resolve a significant
issue. Once Embassy reaches a stable `v1.x` release, a major HAL overhaul may be
considered; no such migration is currently planned.
